# SauceDemo Login Flow Test Plan

## Application Overview

Test the SauceDemo login flow at https://www.saucedemo.com/ only. Each scenario starts independently from a fresh, logged-out login page. The documented shared password is secret_sauce. No Playwright test code is generated by this plan.

## Test Scenarios

### 1. Login Flow

**Seed:** `tests/seed.spec.ts`

#### 1.1. Successful login with standard user

**File:** `tests/login/successful-login.spec.js`

**Steps:**
  1. Start from a fresh browser state and navigate to https://www.saucedemo.com/.
    - expect: The Swag Labs login page is displayed with empty Username and Password fields and a Login button.
  2. Enter standard_user in Username and secret_sauce in Password.
    - expect: Both credentials are accepted as entered.
  3. Click Login.
    - expect: The browser navigates to /inventory.html.
    - expect: The Products page is displayed.
    - expect: No login error is shown.

#### 1.2. Invalid username with valid password

**File:** `tests/login/invalid-username.spec.js`

**Steps:**
  1. Start from a fresh browser state and navigate to https://www.saucedemo.com/.
    - expect: The login page is displayed with empty Username and Password fields.
  2. Enter invalid_user in Username and secret_sauce in Password.
    - expect: The credentials are present in their respective fields.
  3. Click Login.
    - expect: The browser remains on the login page.
    - expect: An alert displays: Epic sadface: Username and password do not match any user in this service.
    - expect: The entered values remain in the fields.

#### 1.4. Locked-out user cannot log in

**File:** `tests/login/locked-out-user.spec.js`

**Steps:**
  1. Start from a fresh browser state and navigate to https://www.saucedemo.com/.
    - expect: The login page is displayed with empty Username and Password fields.
  2. Enter locked_out_user in Username and secret_sauce in Password.

    - expect: The inventory page is not opened.

#### 1.5. Empty username and password

**File:** `tests/login/empty-credentials.spec.js`

**Steps:**
  1. Start from a fresh browser state and navigate to https://www.saucedemo.com/.
    - expect: The login page is displayed with both Username and Password fields empty.
  2. Without entering any text, click Login.
    - expect: The browser remains on the login page.
    - expect: An alert displays: Epic sadface: Username is required.
    - expect: Both fields remain empty.
